# Supply Chain Performance Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze supply chain performance across revenue, orders, delivery performance, warehouses, regions, categories, and products.

This portfolio project uses a realistic sample dataset and does not contain confidential company data.

## Business Objectives
- Monitor overall revenue and order performance
- Track on-time delivery performance
- Compare regions, warehouses, and categories
- Identify top-performing products
- Provide an interactive executive view for decision-making

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Excel sample dataset

## Dashboard Features
### Executive Overview
- Total Revenue
- Total Orders
- On-Time %
- Average Delivery Days
- Total Quantity
- Monthly Revenue & Orders
- Revenue by Region
- Revenue by Category
- Delivery Status
- Warehouse Performance
- Top 5 Products by Revenue

### Customer / Order Detail
- Drill-through analysis
- Detailed order table
- Category and delivery-status analysis

## Interactivity
- Date range
- Region
- Warehouse
- Category
- Delivery Status
- Drill-through navigation
